# Pasco Foods Homepage Redesign

## Overview

This project is a redesigned homepage of the Pasco Foods website created using Shopify.

The objective was to improve the user interface while maintaining the company's branding and product focus.

---

## Features

- Modern homepage layout
- Responsive design
- Hero banner
- Improved typography
- Better spacing

---

## Tools Used

- Shopify
- Shopify Theme Editor
